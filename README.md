# Muhammad Rayhan &mdash; Independent AI Research

Public research site for Muhammad Rayhan's independent AI research program.

## Status

This site is the public front door for reviewed research notes and reproducibility bundles. It does not publish a research claim before the relevant evidence, rights, safety, and independent-check gates are complete.

## Local preview

Open `index.html` in a browser. The site is plain static HTML/CSS and deploys through GitHub Pages.

## Public structure

- `index.html` &mdash; home
- `research-notes.html` &mdash; reviewed research notes
- `open-research.html` &mdash; release standard
- `about.html` &mdash; scope and identity

## Publication rule

Do not add raw internal relay material, private paths, credentials, restricted sources, or unreviewed security claims to this repository.
